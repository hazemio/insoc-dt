# Weeks

One folder per week. Each has the plan (`README.md`) and a `deliverables/` folder for files.

- Plan and tasks: read `weeks/week-XX/README.md`.
- Files (reports, screenshots, slides, exports): upload to `weeks/week-XX/deliverables/`.
- Code: goes in `src/` and `lab/`, not in the weekly folder.
- Large files (PCAPs, datasets, VM images): do not upload. Put them on shared storage
  and add the link to `weeks/week-XX/links.md`.

Role tags: **LEAD** team lead, **NET** network, **SEC** security, **ML** machine learning,
**DASH** dashboard, **ALL** everyone.
